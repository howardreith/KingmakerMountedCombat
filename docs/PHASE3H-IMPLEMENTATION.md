## Repairs and boundaries

**Approach ownership.** The known Horse contradiction was exact: the attack occupied the mount's Standard slot, then `BeginDelegatedMove` required the entire command container to be empty. The replacement contract permits only that exact live pair/intent parent, requires a free Move slot and rejects foreign raw slots, queue, group or previous commands. Native `UnitCommands.Run` pairs Standard/Move interruption; a scoped, exception-safe admission guard preserves only the owning parent. No InterruptAll, queue clearing or global concurrency exception was added. RTWP and mount-current TB use native advancement; only rider-current off-executor movement uses the existing narrow adapter. Native distance/corpulence and LoS determine attack start and moving-target revalidation. The formerly misleading stationary fixture now uses the actual admission predicate, with approach rows separate. The human RTWP pointer regression was not independently reproduced on preview.7; new-build scripted native-handler approach is the evidence, rather than an assumed common diagnosis.

**One native attack sequence and charge.** `MountedPairAttackCommand` now derives from the native UnitAttack adapter and owns the plan, animation, effect lifecycle and native controller charge itself. The historical ChildAttack property refers to that same command. The free ignored-cooldown child is gone. Ordinary mode permits the native full plan; explicit Primary deliberately remains single. Native OnStart replans after approach, when full-round eligibility is known. Completion requires the native terminal lifecycle and all planned attack indices, with recovery after the last attack. Repeated clicks retain the active intent/sequence. Exact target invalidation retires continuation; it does not auto-retarget, turn arbitrary exceptions into success, delete released arrows or suppress native opportunities. Rule/damage/weapon ownership stays native.

RTWP observed plans include longbow 5, melee 4 and Horse Bite/Hoof/Hoof 3 for this fixture. Those are observed native plans, not hard-coded feature counts or a complete Rapid Shot penalty/BAB/haste matrix. Rapid Shot is acquired through its actual native feature/AddFacts toggle; the [native feat rule](https://aonprd.com/FeatDisplay.aspx?ItemName=Rapid+Shot) is a full-attack benefit. TB longbow still selected native Single attack mode despite Standard/Move initially zero, no Staggered or move restriction, and Rapid Shot on. The actual first gate is native `EnabledFullAttack=false` / `IsFullAttackRestrictedBecauseOfMoveAction=true`, not child count. Two equivalent failed full-round attempts ended this diagnostic branch. The fixture supplies native hover/handler input but has no working physical pointer channel; native attack mode was never forced.

**Mount movement state implemented, qualification incomplete.** The new actor-owned record removes the rider cooldown/time projection. It retains movement time, forced-movement time, step time/metres, immunity/AI-step/autostop state and observed Move/Standard expenditure.
