# Diagnostic combat target policy

Status: TODO

Combat target work is locked until explicit user acceptance of the exact Phase 2A visual-review build.

Prefer a suitable real hostile already present in the disposable Working fixture only when it can be exercised without quest or script contamination. Otherwise a project-owned runtime-only target may use one stock, simple, unnamed melee-capable Kingmaker blueprint after exact Working load.

Any runtime-only target must have a recorded stable runtime identity, validated open placement, no quest/dialogue/loot/story dependency, no retained XP or reward, no serialization, and deterministic removal on every cleanup path. Faction, entity, command, and reward residue must be zero. It may never be spawned in Baseline or permanently added to Working.

Temporary equipment, if unavoidable, must be a separate runtime transaction recording and restoring exact equipment and inventory state. Existing ordinary melee equipment is preferred.
