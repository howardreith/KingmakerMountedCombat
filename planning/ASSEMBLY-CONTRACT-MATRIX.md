## Wrath state, entry, exit, and failure summary

- Relationship state is reciprocal and serialized. Mounting validates the master/pet relationship, assigns both halves, disables rider avoidance, toggles the system ability, ensures rider IK, then raises the mount event.
- Dismount clears both halves, restores avoidance, calculates a navmesh-aware side position, disables the ability, and removes the rider part.
- No transaction or `try/finally` spans Wrath's multi-step transition. Invalid direct `Ensure<UnitPartRider>().Mount(...)` can leave an empty part; exceptions can leave partial state until controller or post-load repair.
- Controller invalidation covers consciousness, prone, swallowed, pit, hostility, master/pet/polymorph, and size. It does not use combat start as a cleanup boundary.
- View detach alone does not dismount. Serialization intentionally preserves valid relationships.
